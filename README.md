# סל חדרה — השוואת מחירי סל קניות בסופרים בחדרה

בוחרים מוצרים לסל, והמערכת מראה כמה יעלה הסל בכל סניף בחדרה, מדרגת את הסניפים
מהזול ליקר, ומפרטת מחיר לכל מוצר בכל סניף.

המחירים נלקחים מקובצי המחירים הרשמיים שכל רשת מחויבת לפרסם לפי חוק קידום התחרות
בענף המזון ("חוק שקיפות המחירים").

"גבעת אולגה" בשם או בכתובת הסניף. אפשר לשנות אזור ב־`pricecompare/config.py`.

## מוצרים טריים (מוצרים כלליים)

פירות, ירקות, עוף, בשר ודגים נמכרים במשקל, וכל רשת נותנת להם קוד פנימי משלה, כך
שאי אפשר להשוות אותם לפי ברקוד. בשביל זה יש קטלוג של כ־90 "מוצרים כלליים"
(`pricecompare/generic.py`), למשל "חזה עוף טרי", "עגבנייה", "ביצים L (12)":

- כל מוצר כללי מוגדר בתבנית שם, מילים שחייבות להופיע ומילים שפוסלות
  (קפוא, טחון, מעושן, רוטב וכו׳). למוצרים טריים השם חייב **להתחיל** בשם המוצר,
  כדי ש"רוטב עגבניות" לא ייחשב עגבנייה.
- מוצרים טריים נבחרים רק מפריטים שנמכרים לפי ק״ג. בביצים וירוקים נבדקים גם גודל
  וכמות באריזה.
- בכל סופר נבחר המחיר הזול ביותר מבין הפריטים המתאימים, בלי מחירים נמוכים ב־55%
  ומעלה מהמחיר המקובל (בדרך כלל שגיאת קידוד). בפירוט הסל מוצג שם הפריט שנבחר.
- בדיקות: `tests/test_generic.py`.

בנוסף, פריט עם קוד פנימי קצר מקושר לברקוד האמיתי כשיש בדיוק ברקוד אחד שמסתיים
באותן ספרות ולפחות שתי מילים משותפות בשם.

## תמונות מוצרים

קובצי המחירים לא כוללים תמונות. `python -m pricecompare images` מוריד תמונה קטנה
לכל מוצר שנמכר ב־3 סניפים לפחות, משרת התמונות של רמי לוי (לפי ברקוד), ואורז
אותן לקובצי "ספרייט" של 100 תמונות (`web/img/`), מהפופולרי ביותר. ככה חיפוש של
מוצרים נפוצים טוען רק כמה קבצים קטנים. תמונות שכבר הורדו נשמרות ב־`.cache/thumbs`.
למוצרים הכלליים (טריים) מוצג אימוג׳י: תמונה של מוצר ארוז "דומה" התבררה כמטעה
(רסק עגבניות במקום עגבנייה).

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m pricecompare update     # מוריד מחירים עדכניים (כ־3 דקות) אל web/data.json
python -m pricecompare images     # תמונות מוצרים (בפעם הראשונה כ־7 דקות, אחר כך שניות)
python -m pricecompare serve      # http://localhost:8000
```

## עדכון יומי אוטומטי (GitHub Pages)

`.github/workflows/update-prices.yml` מוריד את המחירים כל בוקר ומפרסם את האתר
ב־GitHub Pages. כדי להפעיל: Settings → Pages → Source: **GitHub Actions**,
ואז Actions → Update prices → Run workflow.

## איך זה עובד

- `pricecompare/sources.py` — הורדת קבצים מארבעה פורטלים (שופרסל, Cerberus, קרפור, Bina).
- `pricecompare/parse.py` — פענוח קובצי XML (UTF‑8/UTF‑16, gzip, הבדלי שמות תגיות בין רשתות).
- `pricecompare/build.py` — איחוד כל הסניפים לקובץ JSON דחוס אחד (כ־1MB ב־gzip).
- `web/index.html` — האפליקציה. כל החישוב קורה בדפדפן; הסל נשמר בדפדפן.

## מגבלות

- מוצרים ארוזים מושווים לפי ברקוד; מוצרים טריים לפי הקטלוג שלמעלה. מוצר טרי שאינו
  בקטלוג (או שם שהרשת כתבה אחרת) לא יושווה בין רשתות.
- אם רשת עוד לא פרסמה את הקובץ של היום, נשמרים המחירים הקודמים שלה (עד 3 ימים),
  והדירוג מציין את התאריך.
- מחירים רגילים בלבד — ללא מבצעים ומחירי מועדון (קובצי Promo עוד לא נקראים).
- ויקטורי, מחסני השוק, ח. כהן וחצי חינם לא נתמכים: האתרים שלהם חוסמים גישה
  משרתים מחוץ לישראל (כולל GitHub Actions).
